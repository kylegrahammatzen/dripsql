# DripSQL

DripSQL is an experimental SQL analytics engine for exploring columnar storage, compression, and memory-efficient query execution on a single node.

## Goals

- Design compact columnar storage layouts for analytical workloads.
- Experiment with compression strategies that keep scans efficient.
- Build a memory-aware execution model for single-node query processing.
- Keep the engine small enough to make storage and execution tradeoffs easy to understand.

## Status

DripSQL is early and experimental. APIs, storage formats, and execution internals are expected to change as the project evolves.
